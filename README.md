# 美無極客服 Concept Demo v5

新增「醫美療程速查」模組，定位是客服自我學習與工作查詢輔助，不是醫療建議系統。

收錄示範：
- PROFHILO® 逆時針
- Density RF 無雙電波
- Thermage® FLX 鳳凰電波
- Ultraformer MPT 海芙音波媚必提
- PicoSure 755 蜂巢皮秒雷射
- Juvéderm® 喬雅登玻尿酸
- SKINVIVE® 聚光針
- 外泌體相關療程／產品

每個療程包含：
- 30 秒看懂
- 常見客問
- 困擾／關鍵字
- 客服可先回答
- 需要轉醫師／專業諮詢
- 公開資料來源

目前仍為本機 Demo，手機與電腦不做跨裝置同步。


## v6 修正
- App 圖示改用官網既有品牌 Logo 比例製作，不再使用三個圓圈的自製圖示。
- 搜尋療程時自動跨全部分類搜尋，不會因為停留在某個分類而顯示 0 筆。
- 增加「皺紋／細紋／法令紋」等常用關鍵字。
- 更新 PWA icon 檔名與 cache 版本，避免手機一直吃到舊圖示。
