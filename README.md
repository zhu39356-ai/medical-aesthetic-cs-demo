# 寵物美容丙級＋寵物急救刷題 PWA v15.0

## v15.0 共同科目衝刺模式
- 共同科目取消「每日固定 10 題」限制，想刷多少就刷多少。
- 第一輪只優先出「從未做過」的共同科目題目；399 題都看過後才進入隨機重複複習。
- 首頁新增 11/8 考試進度提醒：未做題數、距離考試天數、依剩餘題量計算的每日最低建議題數。
- 共同科目答錯或按「不知道」會保留在待複習池；當天不複習會跨日累積，直到之後答對才離開待複習。
- 共同科目中途按「先離開」時，可直接選擇進入累積錯題複習或回首頁。
- 美容每日題數與急救每日題數維持原設定，不受共同科目改動影響。

## v15.0 動物考點速記
- 只使用目前 647 題專業題庫實際出現的考點，不補題庫外知識。
- 收錄 32 個相關題目：產地 24 題、胸型 4 題、步態／步伐 4 題。
- 產地依地區分組，並以「犬類」「鼠類／其他」小標分開。
- 每張動物卡顯示名稱、照片、以及該動物在原始 647 題題幹或選項中被提及的題數。
- 新增圖片小測驗：同一隻動物若同時有產地、胸型、步態等題庫考點，會在同一畫面一起作答。
- 圖片小測驗紀錄獨立保存，不會改動正式 647 題的已做題數、正確率或錯題。
- 動物照片透過 Wikipedia / Wikimedia Commons 即時取得；照片第一次載入需連網，圖片失敗只顯示提示，不影響題庫功能。

## v15.0 題庫載入保護
- 專業 647 題與共同科目原始檔、題目 ID 均未改動，既有作答／錯題／收藏／排除紀錄可沿用。
- 若共同科目 JSON 暫時出現 HTTP 404，但手機 IndexedDB 已有完整 399 題，會直接沿用本機題庫，不再因背景載入失敗跳錯誤。
- Service Worker 將題庫資料放進獨立穩定快取；網路回傳錯誤時會優先回退到已快取版本。
- 非必要圖片檔不再綁死 PWA 安裝流程，單一圖片錯誤不會拖垮整個 App。

## 題庫基準
- 13900 寵物美容專業：647 題，來源 `139003A13 / V114090113`。
- 共同科目：`900060A18 / 900070A17 / 900080A16 / 900090A11`，來源共 400 題；環境保護第 30 題官方標示刪題，因此有效 399 題。
- 寵物急救：80 題自建練習題，與正式美容題庫分開。
- 固定不考的 28 題排除清單維持原設定。

## 更新方式
將本壓縮檔內的所有檔案與資料夾完整覆蓋到 GitHub Pages 專案根目錄，請勿只上傳 `index.html` 或 JavaScript；`data/` 與 `assets/` 也必須一起保留。更新完成後第一次開啟請保持網路連線，確認首頁顯示 v15.0。
